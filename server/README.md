异常类	使用场景	示例
InvalidArgumentException	参数不合法	参数类型错误、必填参数为空
LogicException	程序逻辑错误	不符合程序预期的调用
RuntimeException	运行时错误	文件读写失败、外部服务调用失败
DomainException	值不属于允许的业务取值范围	不支持的货币类型
LengthException	长度不符合要求	字符串长度超限
OutOfBoundsException	请求的数组索引或键不存在	获取不存在的数组键
OutOfRangeException	值超出允许的范围	页码小于 1
UnexpectedValueException	实际返回值不符合预期	API 返回数据格式错误
RangeException	计算结果超出允许范围	数值超出业务计算范围
OverflowException	数值溢出	数值计算溢出
UnderflowException	数值下溢	浮点计算发生下溢
BadFunctionCallException	非法函数调用	调用不允许的函数
BadMethodCallException	非法方法调用	调用不允许的方法
